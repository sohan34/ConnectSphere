# 🎓 ConnectSphere – Alumni-Student Platform

**ConnectSphere** is a cross-platform application that bridges the gap between students and alumni. It allows students to connect with alumni for mentorship, career guidance, and hiring insights, while administrators manage users and updates through a dedicated web portal.

---

## 🌟 Key Features

- 👨‍🎓 **Student-Alumni Chat System** for real-time conversations  
- 🎯 **Guided Mentorship Sessions** and career insights  
- 📢 **Company/Job Updates** posted by alumni  
- 🔐 **Role-Based Access**: Student, Alumni, Admin  
- 🌐 **Admin Web Portal** to manage users and content

---

## 🛠️ Tech Stack

- **Frontend:** Android (Java, XML)  
- **Backend/Database:** Firebase Realtime Database  
- **Authentication:** Firebase Auth  
- **Admin Panel:** Web-based (PHP/MySQL or Firebase Hosting if applicable)  
- **Tools:** Git, Android Studio, Firebase Console
